R dialect policy

Base R and tidyverse are both accepted. Some sessions target a specific tool for learning, but otherwise choose the style that makes the data meaning and checks easiest to audit. You should be able to read both and verify important results.

Repository boundary

The repository has two ownership areas:

course/    instructor-managed; read, render, and copy, but do not edit
work/      student-managed; create answers and commit your work here

Do not change anything under course/. Copy the relevant starter file or folder from course/ to the matching location under work/ before editing it.

Before receiving course updates, save and commit work under work/. We will practice this workflow in Session 2.

git status
git add work/
git commit -m "Save current work"
git fetch upstream
git merge upstream/main
git push origin main

Do not place credentials, protected data, or restricted research data in either directory.

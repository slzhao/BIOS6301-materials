Simulation project: evaluating a weight-loss intervention

Can we reliably estimate and detect the additional weight loss from a new intervention, and do our confidence intervals have the advertised coverage?

The outcome is weight lost after 12 weeks, in kg: positive values mean weight loss and negative values mean weight gain. The control population mean is 1 kg; the intervention mean is 1 kg under the null and 3 kg under the alternative. The true additional weight loss, delta, is therefore 0 or 2 kg. All means, SDs, and distribution choices below are hypothetical teaching assumptions.

2. Plan simulations for different outcomes

Before writing a loop, decide what one observation represents, how outcomes could arise, and what you want to learn. Discuss the three examples below and write one or two sentences under each ADEMP heading for each example. These are hypothetical teaching scenarios, not claims about actual treatments. Only Example A will be implemented in the remaining questions.

Example A — Weight loss (continuous outcome). A study measures kg lost after 12 weeks; negative values mean weight gain. Consider a control mean of 1 kg and an intervention mean of 3 kg, with SDs 4 and 2 kg. Compare 10/40 and 30/40 patients. We want to assess estimation of additional weight loss and the chance of detecting it.

Example B — Smoking cessation (binary outcome). Each person is recorded as having quit or not quit at six months. Consider 100 people per group and quit probabilities of 0.15 for control and 0.25 for intervention. We want to estimate the difference in quit probabilities and assess the chance of detecting an improvement.

Example C — Gene-expression read counts (count outcome). A bulk RNA-seq study measures the read count for one gene in six independent biological samples per group. For this teaching scenario, assume equal sequencing depth. Use a negative binomial model with mean count 100 for control, 200 for treatment, and size = 10 in both groups. The size parameter controls extra variation beyond a Poisson model; it is not the number of samples. We want to estimate the treatment/control log2 fold change and assess whether the analysis detects differential expression. Explain why the distribution must allow nonnegative integers and variance greater than the mean.

6. Run all four design rows

Use B = 1000 for each scenario. Trace one pass through the loop: choose a design row, set its seed, run the scenario, and store the result. Explain how do.call() and rbind() combine the results. B <- 1000
results <- vector(mode = "list", length = nrow(design))

7. Summarize estimation and testing performance

For every scenario, report bias, empirical SE, coverage, rejection rate, and MCSE of the rejection rate. Trace the supplied summary loop for one scenario. Explain why mean() of a TRUE/FALSE condition gives a proportion. Add mean confidence-interval width to the summary. Which values describe the method’s performance, which describe sampling variability, and which describe Monte Carlo uncertainty? Interpret rejection as type I error for delta = 0 and power for delta = 2.

summaries <- vector(mode = "list", length = nrow(design))
for (i in seq_len(nrow(design))) {
  one <- all_results[all_results$scenario == design$scenario[i], ]
  truth <- design$delta[i]
  rejection <- mean(x = one$p < 0.05)
  summaries[[i]] <- data.frame(
    design[i, ], trials = nrow(one),
    bias = mean(x = one$est) - truth,
    empirical_se = sd(x = one$est),
    coverage = mean(x = one$lo <= truth & truth <= one$hi),
    rejection = rejection,
    mcse_rejection = sqrt(rejection * (1 - rejection) / nrow(one)))
}
performance <- do.call(what = rbind, args = summaries)
performance

Session 14 guided lab

Design and evaluate a simulation

Work in BIOS6301-mywork.Rproj. Copy one starter from the separate course clone into work/session14/: Quarto or R Markdown. Keep the course originals unchanged.

Learning goals

Practice reproducible random draws, distinguish a population target from an estimate, and compare two procedures using a small simulation. Interpret Monte Carlo uncertainty with one proportion formula.

Warm-up: random draws and the normal distribution

  1. Run two successive rnorm(3) calls after set.seed(42). Rerun the entire block. Which results repeat?
  2. Save state_before <- .Random.seed, draw one value, and compare with identical(state_before, .Random.seed). Explain the generator’s changing bookmark.
  3. Insert unused <- runif(1) between the two rnorm(3) calls. Explain why the second output changes even though unused is never used.
  4. Call set.seed(99) immediately before the result you want to reproduce. Verify that earlier random work no longer changes that result. Explain why you should not put the same seed inside every replicate.
  5. Evaluate dnorm(0), pnorm(1.96), qnorm(0.975), and rnorm(8). Match them to density height, left-tail area, cutoff value, and simulated observations. Which two functions reverse each other’s question? Why is dnorm(0) not the probability of observing exactly zero?

Tasks following the lecture outline

  1. Specify ADEMP — Let each outcome be SBP reduction: baseline minus 12-week SBP, in mmHg. Positive delta means greater mean reduction with treatment. Use independent normal control and treatment groups with SDs 12 and 4. Compare sizes 10/40 and 30/40 and true differences 0 and 6 (four scenarios). Define the estimand as the population mean difference, treatment minus control. Distinguish this target from the estimator and one sample estimate. Write the five ADEMP headings before running the study. Explain why normal reductions are a useful reference scenario, what prior or pilot evidence would support this model in a real project, and one reason to examine a skewed alternative. State the independence assumption and identify the means and SDs as teaching values.

  2. Inspect one replicate — Generate one dataset. Inspect outcome ranges and group summaries to check the generator, allowing for sampling variation. Explain why simulated data cannot establish that real SBP reductions are normal. Compare Welch and pooled results on that same dataset. Verify the estimate direction, result names, and interval ordering. Exercise a failed constant-outcome sample.

  3. Retain each method and replicate — Inspect the supplied run_study(s, B) function and run a pilot with B = 5. Identify where it generates one dataset, applies both methods, and retains results or errors. Check that five replicates produce ten rows. Both methods must use the same dataset in each replicate.

  4. Run reproducible scenarios — Use B = 1000 for this teaching exercise. Assign each scenario a fixed seed and call set.seed() immediately before running that scenario. Insert an unrelated runif() call before the seed and verify that the scenario results stay unchanged. Do not reset the seed inside the replicate loop.

  5. Summarize performance and failures — For each scenario and method report attempts, failures, bias, coverage, rejection rate, and MCSE for rejection. Use sqrt(p_hat * (1 - p_hat) / B_valid), where B_valid counts successful replicates. Label performance summaries as conditional on success. Interpret rejection rates as type I error when delta = 0 and power when delta = 6.

  6. Interpret the comparison — Compare null calibration, power, coverage, and failure counts across allocations. Draw one rejection-rate comparison with approximate Monte Carlo intervals. Explain why 5.2% from 1,000 replicates need not differ meaningfully from 5%, and why more replicates differ from more patients per trial.

  7. Power for study planning — Use the delta = 6 results to compare Welch power for 10/40 and 30/40 patients. Report rejections, valid trials, power, MCSE, and an approximate 95% Monte Carlo interval. Explain why this interval concerns detection probability rather than the treatment effect. Distinguish power from coverage. Do the results support at least 80% power? Explain what increasing patient numbers changes and what increasing B changes.

Optional extensions

  • Extend the Welch power comparison to more sample sizes or a smaller effect (for example, 3 mmHg). Keep the test rule fixed and refine promising scenarios with more replicates.
  • Add dgm = "skewed" to the design using the supplied helper. Explain why it centers errors using the population mean rather than each sample mean. Keep the estimand unchanged.
  • Report empirical SE, mean model SE, RMSE, mean interval width, and MCSE for bias or coverage.
  • Plan B from a target MCSE using ceiling(p * (1 - p) / target^2). Try B = 4000 and explain why MCSE is about half its value at B = 1000.
  • Explore SimDesign::runSimulation() for running a larger study or rsimsum::simsum() for summarising saved results. No package installation is required for the core lab.

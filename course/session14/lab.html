Session 14 guided lab

Evaluating a weight-loss intervention

Work in BIOS6301-mywork.Rproj. Copy one starter from the separate course clone into work/session14/: Quarto or R Markdown. Keep the course originals unchanged.

Learning goals

Practice reproducible random draws, distinguish a population target from an estimate, and compare two procedures using a small simulation. Interpret Monte Carlo uncertainty with one proportion formula.

Warm-up: random draws and the normal distribution

  1. Run two successive rnorm(3) calls after set.seed(42). Rerun the entire block. Which results repeat?
  2. Save state_before <- .Random.seed, draw one value, and compare with identical(state_before, .Random.seed). Explain the generator’s changing bookmark.
  3. Insert unused <- runif(1) between the two rnorm(3) calls. Explain why the second output changes even though unused is never used.
  4. Call set.seed(99) immediately before the result you want to reproduce. Verify that earlier random work no longer changes that result. Explain why you should not put the same seed inside every replicate.
  5. Evaluate dnorm(0), pnorm(1.96), qnorm(0.975), and rnorm(8). Match them to density height, left-tail area, cutoff value, and simulated observations. Which two functions reverse each other’s question? Why is dnorm(0) not the probability of observing exactly zero?

Simulation project: evaluating a weight-loss intervention

Can we reliably estimate and detect the additional weight loss from a new intervention, and do our confidence intervals have the advertised coverage?

The outcome is weight lost after 12 weeks, in kg: positive values mean weight loss and negative values mean weight gain. The control population mean is 1 kg; the intervention mean is 1 kg under the null and 3 kg under the alternative. The true additional weight loss, delta, is therefore 0 or 2 kg. All means, SDs, and distribution choices below are hypothetical teaching assumptions.

Use the helpers supplied in the starter. The code below gives starting points; complete the TODOs and answer every question in prose.

1. Specify ADEMP

Let each outcome be weight loss: baseline minus 12-week weight, in kg. Positive delta means greater mean weight loss with the intervention. The control mean is 1 kg and the intervention mean is 1 + delta kg. Use independent normal control and treatment groups with SDs 4 and 2. Compare sizes 10/40 and 30/40 and true differences 0 and 2 (four scenarios). Define the estimand as the population mean difference, treatment minus control. Distinguish this target from the estimator and one sample estimate. Write the five ADEMP headings before running the study. Explain why normal weight losses are a useful reference scenario, what prior or pilot evidence would support this model in a real project, and one reason to examine a skewed alternative. State the independence assumption and identify the means and SDs as teaching values.

2. Inspect one replicate

Generate one dataset. Inspect outcome ranges and group summaries to check the generator, allowing for sampling variation. Explain why simulated data cannot establish that real weight losses are normal. Compare Welch and pooled results on that same dataset. Verify the estimate direction, result names, and interval ordering. Exercise a failed constant-outcome sample.

4. Run reproducible scenarios

Use B = 1000 for this teaching exercise. Assign each scenario a fixed seed and call set.seed() immediately before running that scenario. Insert an unrelated runif() call before the seed and verify that the scenario results stay unchanged. Do not reset the seed inside the replicate loop.

B <- 1000L

results <- vector(mode = "list", length = nrow(design))
for (i in seq_len(nrow(design))) {

Optional extensions

  • Extend the Welch power comparison to more sample sizes or a smaller effect (for example, 1 kg). Keep the test rule fixed and refine promising scenarios with more replicates.
  • Add dgm = "skewed" to the design using the supplied helper. Explain why it centers errors using the population mean rather than each sample mean. Keep the estimand unchanged.
  • Report empirical SE, mean model SE, RMSE, mean interval width, and MCSE for bias or coverage.
  • Plan B from a target MCSE using ceiling(p * (1 - p) / target^2). Try B = 4000 and explain why MCSE is about half its value at B = 1000.
  • Explore SimDesign::runSimulation() for running a larger study or rsimsum::simsum() for summarising saved results. No package installation is required for the core lab.

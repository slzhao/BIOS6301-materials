# BIOS6301 Session 2 lab starter

This folder contains a small analysis of synthetic data. Copy the complete folder
from the course clone into `BIOS6301-mywork/work/session02-git-lab/` before editing it. Do not initialize a nested Git repository inside
the copied folder; it is tracked by the student's main private BIOS6301 repository.

Keep the root `BIOS6301-mywork.Rproj` personal project open in RStudio. In the
copied folder, choose `analysis/report.Rmd` or `analysis/report.qmd`, delete the
unused alternative from the copied folder, and work only in the chosen source.
This keeps the RStudio Git pane tied to the personal work repository. The data
are stored in `data/study_summary.csv`.

No file in this repository contains real participant information.

Session 11 guided lab

Four short exercises: conditions and functions

Start here

Work in BIOS6301-mywork.Rproj. Copy either the Quarto starter or the R Markdown starter to work/session11/ in your personal repository. Use just one format.

The starter runs as supplied. Complete the clearly marked TODOs, then Render or Knit again. All data are small synthetic vectors included in the file; the exercises use only base R and the standard stats package. Keep your functions in this report. No extra helper files or data downloads are required.

1. Choose a condition

Lecture connection: one decision with if; one label per value with ifelse().

  • Run the supplied length check for four baseline readings and two follow-up readings. Explain why it avoids a misleading subtraction.
  • Replace followup with c(138, 132, 150, 155) and rerun the same check. You should obtain changes -12, -8, -10, 0. The rows are already matched by participant; equal lengths alone cannot establish that match.
  • For change <- c(-2, NA, 1, 0), replace the placeholder labels with nested ifelse() calls. Return "decrease", "missing", "no decrease", and "no decrease". Keep the supplied any() decision and explain why if (change < 0) would not work.

The any() example asks only whether an observed decrease exists; it does not treat missing observations as known non-decreases.

2. Write and call a small function

Lecture connection: help pages, parameters, defaults, return values, and explicit inputs.

Open help("median", package = "stats") in the Console. For the supplied call stats::median(c(10, NA, 14), na.rm = TRUE), identify the package, function, the default for na.rm, and the supplied argument that overrides it. Use Value to predict the return value and its length, then run the call.

Complete centre_values(x, centre = 0) by replacing its placeholder body with return(x - centre). Run the two supplied calls and save their results:

  • Default center: c(10, NA, 14).
  • centre = 12: c(-2, NA, 2).

In one sentence, explain why passing the center as an argument is preferable to reading a global reference_mean inside the function.

3. Read a function with checks

Lecture connection: validation and early returns.

The complete safe_mean() is supplied. Run its four example calls; do not rewrite it. Explain which branch handles each input:

Input Expected result
c(2, NA, 4) 3
numeric(0) Numeric NA
c(NA_real_, NA_real_) Numeric NA
"4" An error about numeric input

The last call is wrapped in try(..., silent = TRUE) so the expected error can be shown without stopping the report. Missing measurements are allowed; character values are invalid input.

4. Reuse the function and check the result

Lecture connection: quoted column names and refactoring repeated code.

The starter calculates two observed means using repeated code. Replace the two placeholder assignments with calls to safe_mean(), extracting each column with markers[["column_name"]]. Keep the original results for comparison.

Run the supplied isTRUE(all.equal(...)) comparisons. Both should be TRUE; the means should be approximately 5.1 and 10.5. Explain in one sentence what these comparisons tell you about the refactor.

Submit

Submit your completed .qmd or .Rmd file and its rendered HTML, including the short explanations above. Restart R and render the saved file once to check that it works without objects left in the Console.

The lecture’s paired-change helpers and separate R scripts remain reference examples. Sessions 12 and 13 supply the helpers needed for their own labs.

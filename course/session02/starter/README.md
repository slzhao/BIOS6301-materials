# BIOS6301 Session 2 lab starter

This folder contains a small analysis of synthetic data. Copy the complete folder
under `work/` before editing it. Do not initialize a nested Git repository inside
the copied folder; it is tracked by the student's main private BIOS6301 repository.

Keep the root `BIOS6301-materials.Rproj` course project open in RStudio, then open
`analysis/report.qmd` from the copied folder. This keeps the RStudio Git pane tied
to the complete course repository. The data are stored in
`data/study_summary.csv`.

No file in this repository contains real participant information.

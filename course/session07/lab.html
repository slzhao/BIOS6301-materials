Session 7 guided lab

Join, reshape, and clean a small study dataset

Note

Tasks 1–8 use only the main lecture. Work through the selected tasks in class and continue independently as needed. Additional practice is optional. The relationship-check and window-function exercises require optional slides.

Work in your personal BIOS6301-mywork.Rproj. Copy either the R Markdown starter or the Quarto starter into your personal work/session07/ folder. Leave the separate course-materials clone unchanged.

Setup: packages

Today’s main lesson uses dplyr, tidyr, stringr, forcats, and lubridate. If you installed the full tidyverse, these may already be available.

In the Console, check:

requireNamespace("dplyr", quietly = TRUE)
requireNamespace("tidyr", quietly = TRUE)
requireNamespace("stringr", quietly = TRUE)
requireNamespace("forcats", quietly = TRUE)
requireNamespace("lubridate", quietly = TRUE)

Install any package returning FALSE, for example:

install.packages("lubridate")

Keep installation commands in the Console. The supplied library() calls belong in the report. Optional practice 5 needs dplyr 1.1.1 or newer: check packageVersion("dplyr") and update if necessary, then restart R.

Replace Your name in the starter’s author field. Either report format is fine.

Core tasks

1. Row units and keys

State what one row represents in patient_lookup and marker_wide. Use count(id) |> filter(n > 1) to check both tables. Identify the participant appearing only in each table by inspecting the data.

2. Join and inspect unmatched participants

Save joined_wide with a left_join() of marker_wide and patient_lookup by id. Compare row counts before and after. Use anti_join() in both directions. Explain the missing arm value. How many rows would an inner_join() keep?

3. Wide to long

Reshape marker_wide and save marker_long. Use cols = starts_with("marker_w"), names_to = "week", names_prefix = "marker_w", and values_to = "marker". Then use mutate(week = as.integer(week)). Predict the row count and explain what one row represents now.

4. Return to wide

Save marker_back using pivot_wider() with id_cols = id, names_from = week, values_from = marker, and names_prefix = "marker_w". Compare IDs, column names, and values with marker_wide after sorting by ID.

5. Clean and search text with stringr

The documented ID rule is uppercase with no outer spaces. Save patients_text from raw_patients using mutate(): clean id with str_trim() and str_to_upper(); clean arm and note with str_squish() and str_to_lower(). Keep the raw table unchanged. Show the IDs and notes where str_detect(note, fixed("repeat")) is true.

6. Factor labels and order with forcats

Save patients_factor from patients_text. Use fct_recode() to map control to Control and treated to Treatment. Then use fct_relevel() to put Control first. Print the levels and counts. Explain which step changes labels and which step changes only their order.

7. Parse dates with lubridate

Save patients_clean from patients_factor. Convert enrolled with ymd() into enrolled_date. Add enrolled_year and enrolled_month using year() and month(). Inspect the result and check for missing parsed dates with filter(is.na(enrolled_date)). Explain why "03/04/2026" needs a stated month/day or day/month convention.

8. Combine the cleaned data

Save analysis by left-joining marker_long to the id, arm, and enrolled_date columns of patients_clean. Check the row count. Keep week 4 and summarize mean marker by arm using Session 6’s verbs. Explain the group with missing arm instead of silently removing it.

Additional practice

Practices 1–4 reinforce the main lecture. Practices 5–6 correspond to optional slides and are not prerequisites for completing the core lab.

Practice 1. Left versus inner

On marker_long and patient_lookup, compare left and inner joins by ID. Explain why their row counts differ by two rather than one.

Practice 2. Spaces inside a note

Compare str_trim(" repeat visit ") and str_squish(" repeat visit "). Explain which preserves the extra internal spaces.

Practice 3. A complete factor order

For factor(c("a", "b", "c", "a")), use fct_relevel() to set the order to c, b, a. Show the levels and the character values to confirm that reordering did not relabel observations.

Practice 4. Three date formats

Use ymd(), mdy(), and dmy() to read "2026-10-18", "10/18/2026", and "18/10/2026". Show that they represent the same day.

Practice 5. Optional join detail: relationship check

Only after the optional join slides: the supplied conflicting_lookup has two different arm records for P01. Join marker_long to it without a relationship assertion and inspect the row count. Then request relationship = "many-to-one" and explain the expected error. Use the supplied error-display chunk only for this deliberate failure.

Practice 6. Optional window example: previous visit

Only after the optional window slides: arrange marker_long by ID/week, group by ID, and compute change = marker - lag(marker). Ungroup afterward. Explain the missing first change for each participant.

Intentional error in optional practice 5

Only the relationship-check chunk uses error=TRUE so a deliberately failing join can appear in the report. The Quarto equivalent is #| error: true. Other analysis errors should stop rendering so you can fix them.

Exit evidence

Knit/Render your report. Show the join checks, a wide/long round trip, cleaned text, factor levels, and parsed dates. Explain the missing metadata for P05. The expected final analysis has eight participant-visit rows.

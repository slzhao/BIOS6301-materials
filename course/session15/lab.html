Resampling the weight-loss trial

Work in BIOS6301-mywork.Rproj. Copy the dataset and one starter (Quarto or R Markdown) into work/session15/. Keep the CSV and starter in the same folder. All data are synthetic.

One dataset, two questions

We now have one observed dataset. We estimate additional weight loss and ask how uncertain that estimate is, and whether the observed difference is surprising under a specified no-effect null.

weight-loss-trial.csv is the same single synthetic trial used in Session 14’s one-trial example (seed 1403, 10 control and 40 intervention participants). id identifies a participant, arm is ctrl or trt, and y is weight lost after 12 weeks in kg. Positive values mean weight loss; negative values mean weight gain. For the permutation exercise, treat this as a completely randomized trial with exactly 10 control and 40 intervention assignments.

In Session 14 we repeatedly generated new trials from a specified population. Here we keep this dataset fixed and resample it. Do not use the known generating effect as an input to either analysis. We cannot measure coverage or power from this one dataset by treating bootstrap or permutation samples as new real trials.

2. Choose a resampling plan

Discuss three project questions before coding. For each, state the target, method, resampling unit, what stays together, and one assumption.

  • Median tumour thickness: an observational cohort supplies one thickness per patient. We want an SE and interval for the population median.
  • Additional weight loss: a trial randomly assigns 10 control and 40 intervention participants. We want an interval for the mean difference and a test of no effect for any participant. Which operation answers each question?
  • Repeated measurements: each participant has baseline and follow-up measurements. We want an interval for mean within-person change. What must stay together? Would before/after observations alone justify swapping time labels?

Explain why more resamples cannot fix biased sampling, an inappropriate unit, or an unjustified label-shuffling rule. Only the weight-loss trial needs coding.

5. Repeat the bootstrap and estimate uncertainty

Generate 2,000 bootstrap statistics. Report the bootstrap SE and a 95% percentile interval in kg. Why is the SE sd(boot) rather than sd(boot) / sqrt(B)? Explain why the interval is about a population mean difference, not a range containing 95% of participants. Compare the bootstrap SE with Welch’s SE. Does agreement prove that either interval has 95% coverage?

set.seed(1501)
B <- 2000
boot <- replicate(n = B, expr = bootstrap_once(data = trial))
boot_se <- sd(x = boot)
boot_ci <- quantile(x = boot, probs = c(0.025, 0.975))
welch <- t.test(x = trial$y[trial$arm == "trt"],
                y = trial$y[trial$arm == "ctrl"], var.equal = FALSE)
c(estimate = observed, bootstrap_se = boot_se, Welch_se = welch$stderr)

6. Try one allowed permutation

State the sharp null: treatment changes no participant’s outcome. Under the assumed complete randomization, keep outcomes fixed and reassign the same 10 control and 40 intervention labels. Trace permute_once() and explain why jointly shuffling complete rows would not change the statistic. Why is this operation different from sampling patients with replacement?

A zero average effect alone does not imply the sharp null. For observational data, unrestricted label permutation requires a justified exchangeability assumption; it is not automatically valid just because we can shuffle labels.

7. Repeat permutations and calculate the p-value

Generate 999 independent random label permutations. Count statistics at least as extreme as the observed difference in either direction. Calculate (extreme + 1) / (P + 1) and its minimum reportable value. Explain why the reported p-value cannot be zero, what null it tests, and why it is neither the probability that the null is true nor an estimate of power.

set.seed(1502)
P <- 999
perm <- replicate(n = P, expr = permute_once(data = trial))
extreme <- sum(abs(perm) >= abs(observed) - 1e-12)
p_value <- (extreme + 1) / (P + 1)
c(observed = observed, extreme = extreme,
  p_value = p_value, minimum = 1 / (P + 1))
